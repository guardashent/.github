# Guardashent

**Stop AI agents from paying the wrong account.**

AI agents are starting to pay invoices. Guardashent puts independent checks on every action an agent takes, before money moves, so a manipulated invoice or email can't redirect a payment.

A real invoice with fake bank details passes a 3-way match. It doesn't pass Guardashent.
